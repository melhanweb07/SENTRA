# FLOWMINDS'26 — AI-Powered Real-Time Stress & Vulnerability Assessment

**Smart India Hackathon 2026 — Problem Statement SIH26093**
A working prototype (not a mockup): a decision-support layer for first-contact
grievance handling. **AI recommends; trained personnel verify and act.**

> **Prototype AI Assessment — Demonstration Mode.**
> This system does not diagnose mental-health conditions and does not autonomously
> make legal, medical or police decisions. All recommendations require human
> verification. Simulated results are never presented as clinically validated.

## 3-minute judge walkthrough

1. **Sign in** as the counsellor (one click on the login card).
2. **Dashboard** — command-center metrics, live assessment activity
   (FM-2026-0101 is mid-conversation), risk distribution, recent cases,
   critical alerts.
3. **New Case** — select language **Tamil** or **Hindi**, fill the intake,
   tick the consent box, submit. Notice privacy-first fields (age range,
   generalised location, optional name).
4. You land in the **Live Assessment console**:
   - LEFT: conversation (text mode / voice mode).
   - CENTER: live indicator bars + detected signal chips.
   - RIGHT: **Stress Vulnerability Index** dial, contribution breakdown,
     AI recommendations, safety alert + **Escalate** when the threshold is crossed.
   - BOTTOM: **Dynamic Distress Mapping** timeline with event markers.
5. Click **“Run guided demo”** — the scripted multilingual voice conversation
   plays segment by segment. Watch the SVI climb (English script ends at ~80,
   CRITICAL), the safety alert fire mid-conversation, and the timeline rise.
   Or type your own text / use **Simulate voice input** / upload audio.
6. **End Assessment** → the report: SVI, **Why this assessment?** evidence
   cards, the explanation chain (Observation → Indicator → Risk contribution →
   SVI), and AI recommendations marked `requiresHumanVerification: true`.
7. **Human verification** — Accept / Modify (pick final actions) / Reject with
   reviewer notes. This is the human-in-the-loop step.
8. **Create Referral** and **Schedule Follow-up** — both real actions.
9. **Export Report** — downloadable case report with evidence, verification,
   referrals, follow-ups and the full audit trail.
10. Switch the **UI language** (top bar) — nav and key labels localise to
    English / தமிழ் / हिन्दी; conversation analysis works in all three.
11. Explore **Referrals**, **Follow-ups** (mark completed/missed),
    **Analytics**, and — as admin — **Audit Logs** (every action recorded).
12. **Logout** ends the session (audited).

## Architecture

```
Next.js 14 (App Router, TypeScript, Tailwind, Framer Motion, Recharts)
 ├── /lib/ai/            Prototype AI engine (deterministic, explainable)
 │    ├── lexicon.ts         multilingual phrase lexicon (en/ta/hi)
 │    ├── analyzeAssessment.ts  signal detection → indicator scores
 │    ├── svi.ts             Stress Vulnerability Index + weights
 │    └── recommendations.ts support recommendation engine
 ├── /lib/store.tsx      data layer (actions + audit + persistence)
 ├── /lib/demo/seed.ts   demo cases generated by the REAL engine
 ├── /app/api/analyze    REST demonstration of the analysis contract
 └── /app/api/cases      REST demonstration of the case service
```

**Data layer:** the store exposes a typed action interface
(`createCase`, `addSegment`, `verifyRecommendation`, `createReferral`, …).
Every action writes an audit entry. The demo persists to localStorage; in
production the same interface is backed by **Firebase Auth + Firestore** —
swap the implementation, not the call sites.

**Intended production path** (from the FLOWMINDS’26 solution):
`Next.js → WebSockets → Python/FastAPI → Whisper ASR + Librosa speech
analysis → NLP/ML (Hugging Face, Scikit-learn/XGBoost) → SVI engine →
Firebase`. This prototype mirrors those contracts with deterministic
fallbacks so the frontend can be pointed at the real service later.

### The SVI (prototype model — fully transparent)

| Dimension | Weight |
|---|---|
| Safety concern | 26% |
| Distress | 16% |
| Fear | 14% |
| Trauma-related distress | 12% |
| Depression indicators | 12% |
| Anxiety | 10% |
| Social isolation | 10% |

Scores are computed from matched phrase weights + (simulated) speech
features. Levels: **0–24 LOW · 25–49 MODERATE · 50–74 HIGH · 75–100
CRITICAL**. Safety-concern ≥ 60 raises a **Safety Alert** for immediate
human attention — never an autonomous dispatch.

### Voice pipeline

- **Recording:** browser MediaRecorder with live waveform + timer.
- **STT:** Web Speech API when the browser supports it (en-IN/ta-IN/hi-IN);
  otherwise a clearly labelled **Demo AI Simulation Layer**.
- **Upload:** audio upload with simulated transcription.
- **Guided demo:** scripted conversations per language — guaranteed to work
  in any demo environment, no microphone needed.

### Multilingual

English, Tamil and Hindi. Extensible by adding a lexicon block in
`src/lib/ai/lexicon.ts` and a dictionary in `src/lib/i18n.ts`.

## Privacy & safety posture (mirrors the SIH26093 mitigations)

- Explicit consent before any analysis; recorded in the audit log.
- Data minimisation: optional name, age *range*, generalised location.
- Role-based access: counsellor / support officer / admin.
- Every action audit-logged with actor, timestamp, severity.
- Safety alerts flag for human review only — no autonomous police/emergency
  contact. Human-in-the-loop is enforced in the workflow, not just stated.
